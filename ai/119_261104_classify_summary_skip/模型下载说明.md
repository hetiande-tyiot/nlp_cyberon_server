# 当前模型下载

119 现在用的是 **Qwen3.6-35B-A3B-FP8**：FP8 量化（block size 128）的 Hugging Face 权重，不是 GGUF。许可证 Apache-2.0。

官方模型卡（含架构和评测，下载命令不在里面）：

- Hugging Face：https://huggingface.co/Qwen/Qwen3.6-35B-A3B-FP8
- 魔搭：https://www.modelscope.cn/models/Qwen/Qwen3.6-35B-A3B-FP8

未量化原版是 `Qwen/Qwen3.6-35B-A3B`。119 不要下那个。

## Hugging Face

```bash
pip install -U huggingface_hub
huggingface-cli download Qwen/Qwen3.6-35B-A3B-FP8 \
  --local-dir /path/to/Qwen3.6-35B-A3B-FP8
```

需要登录或走镜像时，先设置 `HF_TOKEN`，或 `export HF_ENDPOINT=https://hf-mirror.com` 后再执行上面的命令。

## 魔搭

国内网络用这一条：

```bash
pip install -U modelscope
modelscope download --model Qwen/Qwen3.6-35B-A3B-FP8 \
  --local_dir /path/to/Qwen3.6-35B-A3B-FP8
```

## 下完要有这些文件

目录里要能看到 `config.json`、`chat_template.jinja`、`tokenizer.json`、`model.safetensors.index.json`，以及全部 `*.safetensors`（`layers-*.safetensors`、`outside.safetensors`、`mtp.safetensors`）。缺分片时 vLLM 起不来。

这个目录路径要和 `vllm serve` 的参数、119 的环境变量 `VLLM_MODEL` 写成同一个路径。启动方式见同目录的 `vLLM部署说明.md`。
