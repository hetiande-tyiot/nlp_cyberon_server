# 911 改成 119_261104 + vLLM

911 原本跑 119_0904_addrflow，模型是 GPU0 的 llama-server（TW-119-Model.gguf，port 8091）。
改完之後 911 跑 master 的 119_261104_classify_summary_skip，模型是 GPU0 的 vllm-gpu0（Qwen3.6-35B-A3B-FP8，port 8001）。
912 和 GPU1 都不動，911、912 各用一張卡。asterisk、apiserver 撥 911 的設定不用動，一樣送 port 8100。

從第 1 步開始 911 會中斷，到第 4 步 911 起來為止，大約 3～5 分鐘。

## 安裝

```bash
D=/home/taiyan/project/nlp_cyberon_server/deploy/911_1104

# 1. 停掉 911 和 llama-server，並取消 llama-server 開機自動啟動（不然重開機會跟 vLLM 搶 GPU0）
sudo systemctl stop sop119
sudo systemctl disable --now llama-server

# 2. 裝 GPU0 的 vLLM 並啟動（要等 2～3 分鐘，看到 Application startup complete 才算好）
sudo cp $D/vllm-gpu0.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now vllm-gpu0
journalctl -u vllm-gpu0 -f

# 3. 舊的 llama-server 補充設定移到備份，換成新的
sudo mv /etc/systemd/system/sop119.service.d/llama-backend.conf /etc/systemd/system/sop119.service.d/llama-backend.conf.bak
sudo cp $D/vllm-backend.conf /etc/systemd/system/sop119.service.d/

# 4. 啟動 911
sudo systemctl daemon-reload
sudo systemctl start sop119
```

## 確認

```bash
curl -s http://127.0.0.1:8001/v1/models
systemctl status sop119
curl -s http://127.0.0.1:8100/health     # llm_backend 要是 vllm、llm_loaded 要是 true
nvidia-smi                               # GPU0 上應該只剩 VLLM::EngineCore
```

## 改回 119_0904 + llama-server

```bash
sudo systemctl stop sop119
sudo systemctl disable --now vllm-gpu0
sudo mv /etc/systemd/system/sop119.service.d/vllm-backend.conf /etc/systemd/system/sop119.service.d/vllm-backend.conf.off
sudo mv /etc/systemd/system/sop119.service.d/llama-backend.conf.bak /etc/systemd/system/sop119.service.d/llama-backend.conf
sudo systemctl daemon-reload
sudo systemctl enable --now llama-server
sudo systemctl start sop119
```
